🤖 DLRM 集群调度分析机器人

CS451: Data Intensive Distributed Computing Final Project

项目背景介绍：

这是一个基于 **Spark 驱动的 NL-to-SQL RAG 系统**，旨在通过自然语言查询阿里巴巴 GPU 解耦推理集群（DLRM Trace）的调度数据。

后端使用 **FastAPI (MCP)** 接收问题，通过 **Gemini Function Calling** 将问题转化为 **Spark SQL**，并在 **PySpark** 上执行分布式查询。

你可以尝试以下问题：

  • “统计一下 CN 和 HN 角色各有多少个实例？”
  • “内存请求量最大的前 5 个应用是什么？”
  • “CN 实例的平均调度延迟是多少？”
