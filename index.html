Project Background:

This is a **Spark-driven NL-to-SQL RAG System** designed to query the scheduling trace data from the Alibaba GPU Disaggregated Inference Cluster (DLRM Trace) using natural language.

The backend uses **FastAPI (MCP)** to receive queries, transforms them into **Spark SQL** via **Gemini Function Calling**, and executes the distributed query on **PySpark**.

Example Queries to Try:

  • "Count the number of instances for CN and HN roles."
  • "What are the top 5 applications with the highest memory request?"
  • "What is the average scheduling delay for CN instances?"
